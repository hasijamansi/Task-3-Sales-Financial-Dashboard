# Task 3 – Sales Financial Analysis Dashboard

## Objective
Designed an interactive sales and financial analysis dashboard for business stakeholders using Tableau Public.

## Dataset
Sales_Financial_Dataset

## Tool Used
Tableau Public

## Dashboard 1 – Sales Performance Dashboard
This dashboard provides:
- Total Sales
- Total Profit
- Total Quantity
- Sales Growth
- Sales and Profit by Month
- Interactive Year-Month filter

## Dashboard 2 – Sales Analysis Dashboard
This dashboard provides:
- Sales Trend Over Time
- Sales by Category
- Sales by State
- Sales by Payment Mode

## Key Features
- Interactive Year-Month filtering
- KPI cards for sales, profit, quantity and growth
- Time-series analysis
- Category, state and payment-mode analysis
- Consistent dashboard design

## Key Insights
- Sales and profit fluctuate across different months.
- Sales performance varies across states.
- Category-level sales can be compared to identify major contributors.
- Different payment modes contribute differently to overall sales.
- Interactive filters allow users to analyze performance for specific periods.

- Tableau Dashboard
- Tableau Workbook
- Sales Financial Dataset
